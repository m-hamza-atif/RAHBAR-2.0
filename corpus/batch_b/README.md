# Batch B fixtures

These eleven fictional FAST-NUCES-style files exercise verification and versioning. Their policies are synthetic and should only be loaded into an isolated assignment collection.

- Two byte-for-byte copies exercise SHA-256 duplicate detection.
- The near-duplicate uses different metadata and changes one punctuation mark in the policy body.
- The truncated file has an explicit incomplete-export marker. The hostel file omits its expected page count.
- The academic rules fixture supersedes Batch A's academic rules family under the same logical ID.
- The student records fixture contains a harmless instruction that should surface in the Phase 2 trace tests.
